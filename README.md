Craft Team
---
> [!NOTE]
> This mod only supports Minecraft 1.21.1 (NeoForge 21.x)

My fork of [Mine Team](https://github.com/XiaoHuNao/MineTeam), 
inspired [Better Mine Team](https://github.com/i113w/BetterMineTeam), 
with some code taken from [Slice](https://github.com/ansi-sudo/Slice)

| Command           | Description                                                                      |
|-------------------|----------------------------------------------------------------------------------|
| `/craftteam init` | Initializes the teams (for worlds that have been created before mod installation |

You can command your tamed mobs by holding down the ``` ` ``` key (changeable in controls settings)

![actions menu](https://cdn.modrinth.com/data/nXWn0t9m/images/367d7e31daec5f41ece9e38e99c3c0d8f3a57536.png)

| Action | Description                                          |
|--------|------------------------------------------------------|
| Attack | Follows owner and attacks what they attack           |
| Follow | Follows owner and attacks mobs that hurt their owner |
| Stay   | Stay in place (Endermen still teleport)              |
