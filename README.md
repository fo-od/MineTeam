Mine Team
---
This is my fork of the mod "Mine Team"!

> [!NOTE]
> This fork only supports Minecraft 1.21.1 (NeoForge 21.x)

### Bugs fixed:
- Fixed a bug where the client would lose their team color in the gui, causing missing textures for some buttons.
- Fixed a bug where tamed mobs would target their owner, and not the owner's attackers.
- Fixed a bug where disabling PvP would not work.

### Features added:
- Added a command that initializes the teams `/mineteam init` (for worlds that have been created before the mod was installed)

### Planned features:
- Add a command to add/remove a player to a team.
- Add a mob command menu. Used for actions like: attack, follow, stay.

NOTE: AI assistance was used in the development of this fork. No code was generated by AI though.
This is because I’m new to modding, and it's hard to find resources on modding, so I had to ask AI for guidance.
I made sure to understand what the AI was saying before adding anything.
