Mine Team
---
This is my fork of the mod "Mine Team"!

> [!NOTE]
> This fork only supports Minecraft 1.21.1 (NeoForge 21.x)

### Bugs fixed:
- Fixed a bug where the client would lose their team color in the gui, causing missing textures for some buttons.
- Fixed a bug where tamed mobs would target their owner, and not the owner's attackers.
- Fixed a bug where disabling PvP would not work.

### Features added:
- Added a command that initializes the teams (for worlds that have been created before the mod was installed)
