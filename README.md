Craft Team
---


> [!NOTE]
> This mod only supports Minecraft 1.21.1 (NeoForge 21.x)

| Command           | Description                                                                      |
|-------------------|----------------------------------------------------------------------------------|
| `/craftteam init` | Initializes the teams (for worlds that have been created before mod installation |

### Planned features:
- Add a command to add/remove a player to a team.
- Add a mob command menu. Used for actions like: attack, follow, stay.
